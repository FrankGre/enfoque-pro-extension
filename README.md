# 🚀 Enfoque Pro - Extension de Chrome

**Enfoque Pro** es una herramienta diseñada para eliminar distracciones, limpiar el ruido visual y ayudarte a recuperar tu concentración mientras navegas por la web.

## ✨ Características principales
* **Limpieza Inteligente:** Oculta anuncios y elementos basura automáticamente.
* **Modo Enfoque:** Resalta el contenido principal para una lectura cómoda.
* **Privacidad:** No rastreamos tu actividad; todo el proceso ocurre localmente en tu navegador.

## 🛠️ Instalación (Modo Desarrollador)
1. Descarga este repositorio como un archivo `.zip`.
2. Descomprímelo en tu computadora.
3. Abre Chrome y ve a `chrome://extensions/`.
4. Activa el **"Modo de desarrollador"** (arriba a la derecha).
5. Haz clic en **"Cargar descomprimida"** y selecciona la carpeta de la extensión.
